# Apartamento compacto

Reconstrucción preliminar basada en la planta aportada por el usuario. La cama derecha fija la escala provisional en 1,60 m de ancho. El proyecto separa arquitectura, propuesta `natural_lila`, presentación y producción.

Las dimensiones se infieren de una imagen sin cotas y no sirven todavía como documentación constructiva. Se simplificaron puertas, ventanas, sanitarios y el mueble curvo de la zona social.
