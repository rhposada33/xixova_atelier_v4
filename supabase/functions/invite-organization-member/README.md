# Convites de organização

Função local do Checkpoint A. Usa `SUPABASE_SERVICE_ROLE_KEY` somente no runtime da função.
`ALLOWED_ORIGINS` é uma lista separada por vírgulas. Nenhum secret deve usar prefixo `VITE_`.

O callback com token opaco precisa passar pela suíte local de compatibilidade Auth antes de qualquer deploy remoto.
