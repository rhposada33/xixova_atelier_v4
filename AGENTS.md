# Contexto del proyecto para agentes

- Para tareas de producción, revisión o exportación de vídeo de XIXOVÁ, leer primero `docs/VIDEO_PRODUCTION_LESSONS.md`. Es un índice operativo breve; seguir sus enlaces solo cuando hagan falta detalles.
- Para crear o modificar proyectos estructurados, consultar `docs/agentes/GUIA.md` y los contratos de `xixova/schemas/` antes de editar datos.
- No asumir que una guía sustituye al estado actual: comprobar comandos, archivos, hashes y cambios locales antes de actuar. Conservar el trabajo existente del usuario.
